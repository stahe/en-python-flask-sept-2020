    12. Classes and Objects

    A class is the template from which objects are created. An object is said to be an instance of a class.

    Note: The [shared] file has been placed in the [Sources Root] directory of the project.

    12.1. script [classes_01]: an Object class

    The script [classes_01] demonstrates an obsolete use of classes:

    
# a class
class Objet(object):
    """une classe Objet vide"""
 
 
# any variable of type [Objet] can have attributes by construction
obj1 = Objet()
obj1.attr1 = "un"
obj1.attr2 = 100
# displays the
print(f"objet1=[{obj1}, {type(obj1)},{id(obj1)},{obj1.attr1},{obj1.attr2}]")
# modify object
obj1.attr2 += 100
# displays the
print(f"objet1=[{obj1.attr1},{obj1.attr2}]")
# assign reference obj1 to obj2
obj2 = obj1
# modifies the object pointed to by obj2
obj2.attr2 = 0
# displays both objects - obj1 now points to a modified object
print(f"objet1=[{obj1.attr1},{obj1.attr2}]")
print(f"objet2=[{obj2.attr1},{obj2.attr2}]")
# obj1 and obj2 point to the same object
print(f"objet1=[{obj1}, {id(obj1)},{obj1.attr1},{obj1.attr2}]")
print(f"objet2=[{obj2}, {id(obj2)},{obj2.attr1},{obj2.attr2}]")
print(obj1 == obj2)
# instance type obj1
print(f"type(obj1)={type(obj1)}")
print(f"isinstance(obj1,Objet)={isinstance(obj1, Objet)}, isinstance(obj1,object)={isinstance(obj1, object)}")
# any type is an object in Python
print(f"type(4)={type(4)}")
print(f"isinstance(4, int)={isinstance(4, int)}, isinstance(4, object)={isinstance(4, object)}")

    Notes:

    • lines 2-3: an empty class [Objet];
    • line 2: the class can be declared in three forms:
      • class Object;
      • class Object();
      • class Object(object);
    • line 3: another form of comment. This one, preceded by three "", can span multiple lines;
    • line 7: instantiation of the Object class. The result is an address, as shown in lines 24–26;
    • lines 8–9: direct initialization of two attributes of the object;
    • line 17: copying references. The variables obj1 and obj2 are two pointers (references) to the same object;
    • line 19: the object pointed to by [obj2] is modified. Since [obj1] and [obj2] point to the same object, the displays of the [obj1, obj2] objects in lines 21 and 22 will show that the object pointed to by [obj1] has changed;
    • Lines 24–26: These lines are intended to show that the variables [obj1] and [obj2] are equal. The output of line 26 will demonstrate this. In this comparison, the addresses [obj1] and [obj2] are equal;
    • each Python object is identified by a unique number obtained using the expression [id(objet)]. Lines 24 and 25 will show that the numbers of the objects pointed to by [obj1] and [obj2] are identical, thereby showing that these two references point to the same object;
    • Lines 27–29: The function [isinstance(expr,Type)] returns the Boolean value True if the expression [expr] is of type [Type]. Here, we will see that [obj1] is of type [Objet], which seems natural, but also of type [object]. The class [object] is the parent class of all Python classes. By the nature of class inheritance, a child class F has all the properties of its parent class P, and the function [isinstance(instance de F, P)] returns True;
    • lines 30–32: show that type [int] is also a type [object]. All Python types derive from the class [object];

    12.2. Script [classes_02]: a Person class

    The script [classes_02] demonstrates that a class’s attributes are public: they are directly accessible from outside the class. This is another example of a deprecated use of classes. We include it nonetheless because this type of code is sometimes encountered (Python allows it), and one must be able to understand it.

    
# person class
class Personne:

    # undeclared - can be created dynamically
 
    # method

p = Personne()

    • line 9: the class attributes are denoted by the notation [self.attribut];
    • lines 23–24 show that the object [p] is an instance of both the class [Personne] and the class [object];

    12.4. Script [classes_04]: static methods

    In the [modules] folder, we define the following [Utils] class (utils.py):

    
class Utils:
    # static method
    @staticmethod
    def is_string_ok(string: str) -> bool:
        # is string a string?
        erreur = not isinstance(string, str)
        if not erreur:
            # is the chain empty?
            erreur = string.strip() == ''
        # result
        return not erreur

    Notes

    • Line 3: The annotation [@staticmethod] indicates that the annotated method is a class method and not an instance method. This is evident from the fact that the first parameter of the annotated method is not the keyword [self]. Thus, the static method does not have access to the object's attributes. Instead of writing:
    1
2
    u=Utils()
print(u.is_string_ok("abcd")

    we write

    1
    print(Utils.is_string_ok("abcd")

    Because we wrote [Utils.is_string_ok] above, the method [is_string_ok] is called a class method (the Utils class here). For this, the method [Utils.is_string_ok] must be annotated with the keyword [@staticmethod].

    The static method [Utils.is_string_ok] is used here to verify that a piece of data is a non-empty string.

    12.5. Script [classes_05]: attribute validity checks

    The [classes_05] script introduces new concepts:

    • definition of a proprietary exception type;
    • definition of the [_str_] method, which is the default identity method for classes;
    • definition of properties;
    
# configure the application
import config
 
config = config.configure()
 
# syspath is configured - imports can be made
from utilitaires import Utils
 
 
# a proprietary exception class derived from [BaseException]
class MyException(BaseException):
    # do nothing: empty classroom
    pass
 
 
# person class
class Personne:
    # manufacturer
    def __init__(self: object, prénom: str = "x", nom: str = "y", âge: int = 0):
        # first name: person's first name
        # name: person's name
        # age: age of the person
 
        # parameter storage
        # initializations will be made via setters
        self.prénom = prénom
        self.nom = nom
        self.âge = âge
 
    # method toString of class
    def __str__(self: object) -> str:
        return f"[{self.__prénom},{self.__nom},{self.__âge}]"
 
    # getters
    @property
    def prénom(self) -> str:
        return self.__prénom
 
    @property
    def nom(self) -> str:
        return self.__nom
 
    @property
    def âge(self) -> int:
        return self.__âge
 
    # setters
    @prénom.setter
    def prénom(self, prénom: str):
        # first name must be non-empty
        if Utils.is_string_ok(prénom):
            self.__prénom = prénom.strip()
        else:
            raise MyException("Le prénom doit être une chaîne de caractères non vide")
 
    @nom.setter
    def nom(self, nom: str):
        # first name must be non-empty
        if Utils.is_string_ok(nom):
            self.__nom = nom.strip()
        else:
            raise MyException("Le nom doit être une chaîne de caractères non vide")
 
    @âge.setter
    def âge(self, âge: int):
        # age must be an integer >=0
        erreur = False
        if isinstance(âge, int):
            if âge >= 0:
                self.__âge = âge
            else:
                erreur = True
        else:
            erreur = True
        # mistake?
        if erreur:
            raise MyException("L'âge doit être un entier >=0")
 
 
# ---------------------------------- main
# a Person object
try:
    # instantiation Person class
    p = Personne("Paul", "de la Hûche", 48)
    # object display p
    print(f"personne={p}")
except MyException as erreur:
    # error display
    print(erreur)
 
# another object Nobody
try:
    # instantiation Person class
    p = Personne("xx", "yy", "zz")
    # object display p
    print(f"personne={p}")
except MyException as erreur:
    # error display
    print(erreur)
 
# another person without parameters this time
try:
    # instantiation Person class
    p = Personne()
    # object display p
    print(f"personne={p}")
except MyException as erreur:
    # error msg display
    print(erreur)
 
# you cannot access the __attr private attributes of the
p.__prénom = "Gaëlle"
print(f"p.prénom={p.prénom}")
print(f"p.__prénom={p.__prénom}")
p.prénom = "Sébastien"
print(f"p.prénom={p.prénom}")
print(f"p.__prénom={p.__prénom}")

    Notes:

    • lines 10–13: a class MyException derived from the class BaseException (we’ll cover this point a bit later). It adds no functionality to the latter. It is there solely to have a custom exception;
    • line 19: the constructor has default values for its parameters. Thus, the operation p=Person() is equivalent to p=Person("x", "y", 0);
    • lines 34–45: the class properties. These are methods annotated with the keyword [@property]. They are used to return the values of the attributes;
    • lines 47–77: the class’s setters. These are methods annotated with the keyword [@attributsetter]. They are used to set the values of the attributes;
    • lines 48–54: the setter for the [prénom] attribute. This method will be called every time a value is assigned to the [prénom] attribute:
    1
2
    p=Personne(…)
p.prénom=valeur

    Line 2 will trigger the call to [p.prénom(valeur)]. The advantage of using a setter to assign a value to an attribute is that, since the setter is a function, we can verify the validity of the value assigned to the attribute;

    • line 51: we verify that the value assigned to the attribute [prénom] is a non-empty string. To do this, we use the static method [Utils.isStringOk] seen previously;
    • line 52: the value assigned to the attribute [prénom] is stripped of its leading and trailing whitespace and assigned to the attribute [self.__prénom]. Therefore, the [prénom] attribute is not used here. We could not have done otherwise, or we would have had an infinite recursive call. We could have used any attribute name. The fact that we used the attribute [__prénom] with two underscores at the beginning of the identifier has a special meaning: attributes preceded by two underscores are private to the class. This means they are not visible from outside the class. Therefore, we cannot write:
    1
2
    p=Personne(…)
p.__prénom=valeur

    In fact, we’ll soon see that you can write it, but it doesn’t change the first name. It does something else;

    • lines 53–54: if the value assigned to first_name is incorrect, an exception is thrown. This way, the calling code will know that its call is incorrect;
    • lines 35–37: the [prénom] property. It will be called every time [p.prénom] is written in an expression. The [p.prénom()] method will then be called. Line 37: We return the value of the [__prénom] attribute, since we saw that the setter for the [prénom] attribute assigned its value to the private attribute [__prénom];
    • Lines 56–62: The setter for the [nom] attribute is constructed in a manner analogous to that of the [prénom] attribute. The same applies to the setter for the [âge] attribute in lines 64–77;
    • although the properties [prénom, nom, valeur] are not the actual attributes—which are in fact [__prénom, __nom, __âge]—we will continue to refer to them as class attributes, since they are used as such;
    • lines 19–28: the class constructor implicitly uses the setters for the [prénom, nom, âge] attributes. In fact, by writing [self.prénom = prénom] on line 26, the [prénom(self, prénom)] method is implicitly called. The validity of the [prénom] parameter will then be checked. The same applies to the other two [nom, âge] attributes;
    • with this model, incorrect values cannot be assigned to the [prénom, nom, âge] attributes of the class;
    • lines 30–32: the function __str__ replaces the method previously called identity. The name [__str__] (with two underscores before and after) is not insignificant. We will see this later;
    • lines 83–86: instantiation of a person, followed by display of their identity;
    • line 84: instantiation;
    • line 86: display. The operation requests that the person p be displayed as a string. The Python interpreter then automatically calls the p.__str__() method if it exists. This method plays the same role as the toString() method in Java or in .NET languages;
    • lines 87–89: Handle any MyException-type exception. Then display the error;
    • lines 91–99: same as above for a second person instantiated with incorrect parameters;
    • lines 102–109: same as above for a third person instantiated with default parameters: no parameters are passed. The default values of these parameters in the constructor are then used here;
    • Lines 112–117: We stated that the attribute [__prénom] is private and therefore normally not accessible from outside the class. We want to verify this;
    • lines 112–114: we assign a value to the attribute [__prénom], then check the values of the attributes [__prénom] and [prénom], which should normally be the same;
    • lines 115–117: we repeat the operation, this time initializing the attribute [prénom];

    12.8. Script [classes_08]: creation of a class derived from the Person class

    In the [myclasses] module, we define the following [Enseignant] class:

    
# class Teacher
class Enseignant(Personne):
    # manufacturer
    def __init__(self, prénom: str = "x", nom: str = "x", âge: int = 0, discipline: str = "x"):
        # first name: person's first name
        # name: person's name
        # age: age of the person
        # discipline: discipline taught
 
        # parent initialization
        Personne.__init__(self, prénom, nom, âge)
        # other initializations
        self.discipline = discipline
 
    # toString
    def __str__(self) -> str:
        return f"enseignant[{super().__str__()},{self.discipline}]"
 
    # properties
    @property
    def discipline(self) -> str:
        return self.__discipline
