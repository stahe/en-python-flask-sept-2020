# Introduction to Python 3 and the Flask Framework

This repository contains the HTML website for the course "Introduction to Python 3 and the Flask Framework Through Examples".

🔗 **View the online documentation:** [https://stahe.github.io/en-python-flask-sept-2020/](https://stahe.github.io/en-python-flask-sept-2020/)

---

## 📝 Contents

This project offers a list of Python scripts covering various topics:
* The fundamentals of the language.
* MySQL and PostgreSQL database management.
* TCP/IP network programming (HTTP, POP3, IMAP, SMTP protocols).
* MVC web programming with the Flask framework.
* Three-tier architectures and interface-based programming.

## 🎯 Target Audience

This collection of examples is intended for:
* Developers who have already used a scripting language (Perl, PHP, VBScript).
* Developers familiar with typed languages (Java, C#) who wish to explore an object-oriented scripting language.

> ⚠️ **Note:** This document is not suitable for readers with little or no programming experience.

## 💡 Philosophy

This project is neither a comprehensive course nor a collection of "best practices." Its goal is to provide concrete examples to help you get started with Python 3 and Flask. The code is provided as-is, and some scripts could be optimized.

To get the most out of this content, **active reading** is required: you must analyze the code, read the associated comments, and observe the execution results.
